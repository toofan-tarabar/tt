# نوبت بارگیری LPG طوفان ترابر

داشبورد آنلاین برای پیگیری نوبت بارگیری، که اطلاعاتش رو مستقیم و به‌صورت زنده از گوگل شیت می‌خونه.

## نحوه انتشار روی GitHub Pages

1. یک ریپازیتوری جدید (public) توی گیت‌هاب بساز.
2. همه‌ی فایل‌های این پوشه (`index.html`، `style.css`، `app.js`، `config.js`) رو داخل ریپو push کن.
3. برو به `Settings` → `Pages`.
4. زیر `Build and deployment`، گزینه‌ی `Source` رو روی `Deploy from a branch` بذار.
5. برنچ رو `main` (یا `master`) و پوشه رو `/ (root)` انتخاب کن، بعد `Save`.
6. بعد چند دقیقه، لینک سایتت به این شکل در دسترس میشه:
   `https://USERNAME.github.io/REPO-NAME/`

## اگه لینک گوگل شیتت عوض شد

فقط فایل `config.js` رو باز کن و سه تا لینک `SHEET_URLS` رو با لینک‌های جدید (که از `File → Share → Publish to web` با فرمت CSV می‌گیری) جایگزین کن.

## نکات

- داده‌ها هر ۶۰ ثانیه به‌صورت خودکار به‌روزرسانی میشن (قابل تغییر در `config.js`، متغیر `AUTO_REFRESH_SECONDS`).
- دکمه‌ی «به‌روزرسانی» بالای صفحه هم برای رفرش دستی هست.
- ستون‌های وضعیت باید دقیقاً یکی از این سه مقدار باشه: «در حال بارگیری»، «منتظر بار»، «بار شده».
